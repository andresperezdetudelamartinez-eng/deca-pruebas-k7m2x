# Laboratorio de integración GitHub

Repo de pruebas del DeCA. Se puede borrar entero.

Este repositorio se usa además como laboratorio desechable para probar
integraciones reales con la API de GitHub. No contiene datos personales ni
credenciales.

## Proyecto de prueba

`textkit` es una utilidad mínima de texto con una función `slugify` y su
conjunto de pruebas.

Ejecutar las pruebas:

```bash
python3 -m pytest -q tests/test_slugs.py
```
